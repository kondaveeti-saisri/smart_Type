#  SmartType — Simple Autocomplete System

##  Overview
**SmartType** is a simple Python project that mimics a real-life autocomplete or search suggestion system — like the ones used in Google Search or VS Code.  
The program takes a list of words from the user and provides real-time suggestions based on the letters typed.

---

##  Objective
- To understand how autocomplete or search suggestions work.  
- To find words that share a **common prefix** with user input.  
- To implement a simple, user-interactive system in Python.

---

##  Features
✅ Accepts dynamic user input (no file needed).  
✅ Displays all matching words as suggestions.  
✅ Allows user to exit easily with the `exit` command.  
✅ Simple, readable, and beginner-friendly code.

---


---

##  How It Works
1. The program first asks the user to input a list of words (your “dictionary”).  
2. After typing `done`, it starts suggestion mode.  
3. When you type any prefix (like "inte"), it shows all words starting with that prefix.  
4. Type `exit` to quit.

---

##  Concepts Used
- **String Matching** using `startswith()`  
- **Lists and Loops** for storing and searching data  
- **User Input Handling**  
- **Common Prefix Logic** (used in autocomplete)
